# Every file under packaging/ and what an image does with it. The one list a packager reads for files;
# the programs are in packaging/shipped.txt. Read and checked by scripts/check-packaging-files.sh (the gate
# runs it): every file under packaging/ is listed exactly once, every listed source exists, and no
# install path is taken twice.
#
# One line per file, four whitespace-separated fields:
#   <source>  <install path>  <mode>  <when>
# source        a path under packaging/, relative to the repository root.
# install path  where the image puts it: an absolute path, or BOOT/<name> for the root of the boot medium
#               (the built U-Boot script). `-` only for a file that is never installed.
# mode          0644 or 0755 for a file copied in with that mode; `append` for a fragment appended to the
#               install path (an existing file). The header of each source names its install path too.
# when          one or more words from the fixed vocabulary, joined by commas; all of them must hold:
#                 always   every image
#                 systemd  an image that runs systemd
#                 busybox  an image without systemd (BusyBox init)
#                 udev     an image with udev (its rules run there)
#                 orion    an image that ships lemnos-orion
#                 gadget   a board whose board file has a usb-gadget device (`driver = "usb-gadget"`)
#                 kmod     an image that ships lemnos.ko
#                 uboot    a U-Boot board that boots from a boot partition (boot.scr)
#                 ubi      a U-Boot board that boots from raw NAND with UBI (boot.scr from boot-ubi.cmd)
#                 never    never installed: documents and this list (no install path; `always` and `never` stand alone)
#
# Systemd and BusyBox images both take the same daemon and privilege path (packaging/README.md).
