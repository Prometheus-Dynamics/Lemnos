# E24 board run: hardware watchdog on a CM5

Status: untested on board.

The driver is `drivers/hw-watchdog`. Its tests run on a mock node (a plain file) and a fake sysfs
tree, so none of them arms a real watchdog. This run checks what the mock cannot: the real device
resets the board when lemnosd stops feeding it.

Run in a local session on the CM5 (Raze #2), under `/run/lock/board-gpu.lock`. Build on NVMe or SSD,
never on the Github HDD. Record CM5 timings only.

**Arming and reset kill the board's watchdog on purpose. Do this only with nothing else on the board
you need to keep.** Each step names what to record.

1. Confirm the device and its attributes before anything opens it:
   `ls /dev/watchdog*`, then `cat /sys/class/watchdog/watchdog0/{identity,timeout,timeleft,bootstatus,state}`.
   Record which exist. `timeout` is the device's own value (seconds).
2. Add a board file entry with `driver = "hw-watchdog"` and `config = { device = "watchdog0", timeout_s = <timeout> }`.
   Start lemnosd. Opening the node arms the watchdog, so the board now resets if feeding stops.
3. Check the feeding: `lemnos-ctl` shows the device as `Ok` (a mismatched `timeout_s` shows `Degraded`).
   Watch `/sys/class/watchdog/watchdog0/timeleft` for a few seconds and confirm it stays near the timeout
   and does not fall. Record the observed refill cadence against half the timeout.
4. Make the failure path visible: `chmod` is not enough, so stop feeding by killing lemnosd with
   `kill -STOP <pid>` (not `pkill` by name). Confirm the board resets when `timeleft` runs out, about
   one timeout after the last feed. Record the reset time.
5. Confirm the magic close is never sent: after a clean lemnosd stop (SIGTERM) the board must still
   reset at the timeout. A reset here means the driver did not write `V`.
6. Record the bootstatus after the reset (`bootstatus` should show the watchdog caused the reset) and
   the lemnosd CPU use while feeding at idle, on the CM5 only.

Results go below this line: the command output, the timings, and anything that did not match.
