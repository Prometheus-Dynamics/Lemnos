# E35 board run: k230-ai2d

Status: untested on board, and nothing here can run a job yet. The crate carries the kernel
interface's layouts (pinned against gcc and clang for riscv64 and riscv32), jobs checked against
the dma-bufs a caller holds, and the `image.scaler/1` job server, all tested on a played-back
block. There is no Linux `Device`: the reference gives no register map (the vendor's prebuilt
runtime programs the block from user space), and the kernel's import answers the address of a
dma-buf's last scatter-list piece. See the crate docs.

Run in a local session on a K230 board running the K230 Linux SDK kernel
(`ruyisdk/linux-xuantie-kernel` at `7d4e1f444f461dbe3833bd99a4640e7b6c2cd529`, as
`kendryte/k230_linux_sdk` at `fc6cc21` pins it). The CM5 has no such block. Build on NVMe or SSD,
never on the Github HDD. Module loads and unbinds are allowed; report each. Stop anything else
that uses the node first (the vendor runtime, any demo): the kernel resets its one import list on
every open.

## Checks

These confirm the interface facts the crate pins, so that a `Device` can be written on them.

1. **The node and the module.** `ls -l /dev/k230-ai2d`; `lsmod | grep ai2d`;
   `grep k230-ai2d /proc/interrupts` (interrupt 191); `cat /proc/iomem | grep 80400c00`. Record
   the kernel version and whether the driver is built in or a module.
2. **The requests.** With a small program (a few lines over `libc::ioctl`, kept out of the
   repository) importing a 64 KiB dma-buf from `/dev/dma_heap/linux,cma` with request
   `0xc0104100` and removing it with `0x40044101` and the descriptor number as the argument. Pass:
   the import answers `0` and a non-zero address inside the CMA region (`dmesg | grep -i cma`), the
   removal answers `0`, and a second removal of the same number answers `EINVAL`. Record the
   address.
3. **The last piece.** Import a 4 MiB dma-buf from `/dev/dma_heap/system` (if present) the same
   way. Record the address. If it differs from the address of the same buffer imported by a
   driver that answers the first piece (or lies near the end of a page-sized piece), the
   last-piece behaviour is confirmed: such buffers must never reach the block.
4. **Completion.** Not runnable without the register map. Record whether `poll` on the node with
   no job running stays quiet for 5 s (it must).

Record each result here.
