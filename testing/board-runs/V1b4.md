# V1b4: the location text and the unit state, on the reference board

Untested on board. These are description values only: no hardware path or register changed.

## The check

1. `lemnos-ctl show` for the thermal zone and the hwmon fan: each shows a `location` line with the
   zone's or the fan's sysfs directory (`/sys/class/thermal/thermal_zone0`, `/sys/class/hwmon/hwmonN`).
2. `lemnos-ctl show` for a device with a dimensionless item (a switch, the uvc counters): `unit
   dimensionless`; for an item whose unit the driver did not say: `unit unknown`; for a volt
   reading: `unit V`.
