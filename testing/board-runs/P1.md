# P1: identity facts on the reference board

Read-only checks. Nothing is written to the board, no module is loaded, no slot is changed.

## Checks

1. The serial equals what the older software used. Run:

       grep -i '^serial' /proc/cpuinfo
       od -An -c /proc/device-tree/serial-number

   Expected: both give the same 16 lowercase hex digits, the first with no trailing newline in the
   device-tree copy. Recorded as verified in `docs/identity.md` when it matches.

2. The tool reads the same serial from the board file. With a board file that names
   `kind = "device-tree"` and nothing else:

       lemnos-identity --board <board file> --data -

   Expected: `family=`, `serial=` (the value from check 1), `model=` when the board file gives a name.
   Exit status 0.

3. The recovery and flasher image reads the same serial. Run check 2 with that image's board file.
   Expected: the same `serial=` line as check 2.
