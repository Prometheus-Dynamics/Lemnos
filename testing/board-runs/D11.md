# D11: USB backend

Status: untested on board. `UsbfsHost` and `UsbfsDevice` are covered by host tests over fixture
sysfs/devfs directories and a recording stand-in for usbdevfs, including crafted completions. No
test has opened, claimed or reset a real USB device, and none has reached one through this backend.

Run on the CM5 with the board lock named in `AGENTS.md`. These paths have never run through this
crate:

1. Enumeration: `UsbHost::enumerate` against `/sys/bus/usb/devices` must list the plugged-in
   devices with their vendor, product, class, speed and bus/address, and leave out root hubs.
2. Open, descriptors: `open` on a device that nothing holds, then `config_descriptor(0, ..)` must
   return the same bytes `lsusb -v` shows for its configuration, and an out-of-range index must
   return `NotFound`.
3. Claims: `claim_interface` on an interface with no kernel driver must succeed and
   `release_interface` must free it. On an interface a kernel driver holds it must return `Busy`:
   this backend never unbinds a driver.
4. Control: a `GET_DESCRIPTOR(device)` `control_in` must return 18 bytes with the device's IDs. A
   `control_out` with the IN bit set must be refused without reaching the device.
5. Bulk and interrupt: on a device with those endpoints, `bulk_in` and `bulk_out` must move the
   expected bytes and `interrupt_in` must return an event or `Timeout`. Interrupt reads use the
   kernel's bulk ioctl, as the reference did.
6. Isochronous: on a webcam-class device after selecting a streaming alternate, `iso_in` at 32
   packets per call must deliver every packet at its capacity offset with `ok` and `received`
   filled in, for a sustained run, with no packet errors the reference did not also see. Compare
   frame rate and packet errors with the reference, and count allocations after the first call
   (expected: 0).
7. Failures: unplug during `iso_in`, and expect `Unavailable`, no panic and no hang. A very short
   timeout must return `Timeout` and leave the next call working. A URB the kernel keeps past the
   grace must yield `Busy` until it returns.
8. Timeouts: `Duration::ZERO` and a sub-millisecond timeout must return within a few milliseconds
   and never wait forever.
