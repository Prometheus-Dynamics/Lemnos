# E20 board run: A733 deinterlacer (`/dev/deinterlace`)

Status: untested on board. The request structures and numbers are pinned against gcc (x86_64)
and clang (aarch64) on `drivers/di/drv_div3x/sunxi_di.h` of the Radxa `allwinner-bsp` tree at
commit `a842bb8dc74608ba13975c97c31b9518f1976c01`. Every check that stands between a caller and
the block (each plane against the dma-buf's real size, nonzero chroma offsets, strides, sizes,
frame counts per mode, every request slot naming a held buffer) has passed its tests on memfds,
and the settings sequence and backoff over a played-back device. No request has reached the
block: this PR has no Linux `Device` (no safe public request for this node exists in
`lemnos-linux-sys`; see the crate docs), so checks 3 to 6 wait for it.

Run in a local session after the missing piece lands, on an A733 board running the Radxa BSP
kernel with `/dev/deinterlace` present. Build on NVMe or SSD, never on the Github HDD. Module
loads and unbinds are allowed; report each.

## Checks

1. **Before anything else: the kernel's layout.** `zcat /proc/config.gz | grep -E
   'SUNXI_DI|AW_DI'` (or the board's kernel config). Pass: `CONFIG_SUNXI_DI_V3X=y` and
   `CONFIG_SUNXI_DI_SINGEL_FILE` not set. If it is set, stop: the kernel's structures are larger
   than the crate's and a request would be read past its end.
2. **The node.** `ls -l /dev/deinterlace`; `dmesg | grep -i -e deinterlace -e 'di '`; record the
   kernel version and the `ip_version` from `DI_IOC_GET_VERSION`.
3. **Every mode.** With dma-bufs from `/dev/dma_heap/system`, 720x480 (and 1920x1080), NV12 and
   YUV420: run `Weave`, `Bob`, `Motion` with and without noise reduction (YUV420 outputs),
   `MotionFieldRate`, and `NoiseOnly`, over a synthetic interlaced input whose top field is all
   Y=0x20 and bottom field all Y=0xe0. Pass: each job returns; `Weave` output equals the input
   byte for byte; `Bob` output rows are all one field's value; outputs outside the frame's planes
   (fill the buffers' tails with 0x5a first) are untouched; `dmesg` shows no IOMMU fault.
4. **Which field is which.** Run `Bob` with `Field::Top` and with `Field::Bottom`. Record which
   gives Y=0x20 (the top field). The header's comment says `base_field` 0 is the top field; the
   kernel's log prints the opposite.
5. **Reads past a row.** Repeat check 3 with frames whose stride equals the width and whose
   buffer ends exactly at the last plane's last byte (a dma-buf of exactly that size, page-rounded
   by the heap: record the rounding), at widths 4, 36 and 2048. Pass: no IOMMU fault in `dmesg`.
6. **Recovery.** While jobs run in a loop, unload the module or unbind the device (report which),
   wait 20 s, and load or bind it again. Pass: `run` answers `Device` and then `BackingOff`, with
   delays from 250 ms doubling to 8 s and holding there; once the node is back the next due job
   reopens, applies its settings from a reset, and passes.
