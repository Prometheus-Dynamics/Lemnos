Read `AGENTS.md` and `docs/design.md` first.

## Creates

`engine/host/src/stream/`, `backends/sim` additions

## Read on dev

- `crates/lemnos-abi/src/desc.rs`
- `docs/dma.md`

## Build

- Pools, buffers, fences, accounting. A shared ring between a producer and the consumer.
- An opaque `u64` frame identity Lemnos never interprets.
- Set up over the wire, then no socket per frame.
- `StreamOpen` is in the protocol and `lemnosd` refuses it with `NOT_SUPPORTED`. Serve it here, passing descriptors with `SCM_RIGHTS` through `backends/linux-sys`, and add taking a stream to `engine/client` (A13 left this out: receiving a descriptor needs `unsafe`, which that crate doesn't allow).

## Proof

Simulated producer and consumer. 0 allocations per frame.
