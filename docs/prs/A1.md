## Build

- Branch `next` from `dev` and remove everything else in one commit.
- Workspace members are globs: `engine/*`, `backends/*`, `service/*`, `contracts/*`, `drivers/*`, `testing/crates/*`. Adding a crate never edits the root. Every directory directly inside those folders must be a crate.
- Pre-declare workspace dependencies (embedded-hal 1.0, embedded-hal-async, libc, tokio).
- `Cargo.lock` is git-ignored until F3, so parallel PRs can't conflict on it.
- `[profile.service]` keeps fat LTO, `opt-level = z` and strip, but uses `panic = unwind`.
- CI runs only for PRs into `next`: format, clippy with warnings denied, tests, boundary check.
