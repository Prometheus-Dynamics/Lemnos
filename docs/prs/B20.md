## Build

- Publishes any device from its description, with no device-specific code.
- Pushes on change, no fixed rate.
- Compares the node id in the session welcome with `ORION_NODE_ID` and refuses to publish when they differ, because Orion refuses a foreign node's records.
- Depends on Orion at `a89ebd5`.
