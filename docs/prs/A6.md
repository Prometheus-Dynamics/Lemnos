## Build

- `#[contract("name", version = N)]` generates the trait's client, its `serve` dispatcher, method numbers and a description.
- `#[driver("name", provides = [..])]` generates the manifest from `#[needs]` fields.
- Method numbers are stable and declared, never derived from order.

## Proof

Compile-pass and compile-fail tests with `trybuild`. Generated code builds `no_std`.
