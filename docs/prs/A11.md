## Build

- Panic boundary and deadline on each driver call.
- Retry after 1 s, doubling to 8 s, forever. Never auto-off.
- Manual off and on. `disabled = true`. Off and backed-off state visible; backoff clears itself.
- Configured auto-off only as an explicit policy.

## Proof
