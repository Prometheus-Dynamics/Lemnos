# A5: Driver model

**Group:** A. Foundation

**Wave:** 4

**Needs:** A4

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Creates

`engine/core`

## Read on dev

- `crates/lemnos-device/src/{model,fixed}.rs` (units and fixed-capacity storage only)

## Build

- `Tag`, `Need`, `Manifest`, `Config`, `Resources`, `Driver`, `Health`, `Description` (values, units, controls, actions). See the shared interfaces section.
- No `DeviceClass`. No `Sensor`, `Control`, `Pixels` or `Composite` traits.
- Works with no allocator; collections behind an `alloc` feature.

## Proof

Unit tests. A handwritten fake driver binds and describes itself. Builds `no_std`.
