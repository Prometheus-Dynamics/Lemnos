# Lemnos

Lemnos talks to hardware without knowing what the hardware is. It is given a driver, the driver
says what it needs to talk to, and the driver describes the device to whoever needs it.

This is the `next` branch, a clean-slate rebuild in progress. `dev` is the current code and the
reference for this work.
